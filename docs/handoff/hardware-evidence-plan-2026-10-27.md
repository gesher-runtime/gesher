# Unmet hardware and interactive evidence (2026-10-27)

These are concrete required environments from existing source contracts,
not new approval gates. None is waived because the hosted runners lack it.
Software implementation and deterministic CI work can continue independently.
All compilation and executable fixtures must still run in CI, including on
any future equipped/self-hosted Windows runner; do not run local fixtures.
The repository does not currently establish an available equipped runner for
the rows below. Equipment/session provisioning belongs to the project owner
or CI operator; track owners design and run the checks, the integrator audits
the exact source/run and evidence before closure.

not prevent ongoing software slices, source audits or existing hosted tests.
