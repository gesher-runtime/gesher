Candidate only: install document-created bootstrap before navigation, construct listener object only when early captured realm origin matches AndroidX rules, and transport operations through CDP Runtime binding. Native delivery must independently match a live unique engine execution context and engine origin in its own session; neither page-provided origin nor frame label authorizes anything. A missing, unknown, stale, mismatched or reordered identity rejects delivery. Reply targets the retained session and unique context, never the newest page. Top-level host object and unscoped frame host objects must not be used as transport. Early script origin is only a provisional exposure gate, not native authorization. This scheme could avoid needing a CDP-to-COM frame identity mapping, but it has not been proved safe: parent manipulation, prototype tampering before bootstrap, inherited/opaque origins and injection order may invalidate it.

Before implementation, build an independent CI-only experiment from the existing realm probe. Await document-created script installation and CDP Runtime binding setup before navigation; auto-attach OOPIF sessions with explicit bounded resume, retain original absolute deadlines. The actual first page script must test presence and invoke the exposed object; native verifies binding event's session, engine context unique ID, origin and parent/main classification independently. Positive siblings and nested cases must be distinguished; disallowed, sandbox opaque, blank/srcdoc inherited, cross-origin, wildcard and port negatives must actively attempt forged direct binding. Capture both native accepted and denied counts, not guest markers alone. Independently race frame creation and navigation, held old-document call and replacement, destroyed context/session and stale reply with no fallback; check no post-retirement callback. Probe all missing or ambiguous events as failures and retain original Web3 controls in production qualification. The controlled names correlate fixture reports only; they do not establish identity authority.

If the binding is missing for first-script OOPIF or context event arrives too late, fail the original timing assertion; do not extend deadlines, hide missing nested frames or retry unchanged source. If bootstrap origin differs from engine origin, or tampering can influence exposure, the candidate fails. Test bootstrap property mutation by same-origin parent and page in addition to opaque/inherited origins, and show first-script execution relative to registration; positive results do not prove origin values cannot be forged in other browser states. This proposal remains research only, pending independent peer and actual CI; no Web4 conformance, safety, full or release qualification is claimed.
