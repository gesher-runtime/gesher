# Annex-B scanning through complete MP4 finalization

This is a focused efficiency proposal for issue #56 **M09**, preserving the existing AVC/muxer behavior. In the final host campaign, complete-file CPU falls **1.396→1.012 ms at 720p (−27.48%)**, **2.589→1.825 ms at 1080p (−29.49%)**, **7.053→3.199 ms at 4K (−54.65%)**, and **2.702→1.743 ms through the codec-config sample path (−35.49%)**. Each of these four steady workloads improves in all six paired ABBA blocks.

The same candidate has material costs: the genuine 16×16 one-frame file rises **35.556→55.599 µs (+56.37%, five of six blocks adverse)**; the length-prefixed AVC payload control rises **695.811→732.647 µs (+5.29%, four blocks adverse)**. Opaque dense-zero and escaped-zero payload controls cost **+40.52%/+20.84%**. The helper's measured static frame grows **16 bytes** on each compiled target. These results support review of a targeted large-stream optimization; they do **not** establish a universal win or acceptance of an issue-wide regression budget.

## Scope and preserved bytes

The only production change is `compat/media/encode/codec_config.cc::SplitAnnexB`. Each possible delimiter begins with zero. After the original zero-leading scalar checks, the helper uses a bounded, alignment-safe eight-byte `memcpy` and unsigned zero-byte predicate to skip only words containing no zero. The subtraction mask is used as a boolean, never interpreted as byte positions. A delimiter spanning a word edge cannot be skipped because its first zero prevents skipping that word. Every load stays inside the supplied range, and every advance preserves `i <= n`.

The existing returned pointer/length sequence remains exact, including leading garbage, three- and four-byte prefixes, consecutive prefixes and empty interior units, trimming zero bytes before a later delimiter, retaining the last unit's trailing zeros, and omitting an empty final unit. Separate input buffers do not synthesize a cross-buffer prefix. Inputs are never modified and returned views remain borrowed; no new ownership or source lifetime is introduced. No codec/profile, capability, error response, sample substitution or media format is added.

The unchanged actual call sites include Media Foundation AVC output, MediaCodec encoder configuration, and MP4 sample/configuration/final CSD handling. This report measures the complete MP4 path; it does not infer an encoder, device, JNI or application speedup. M07 additional codecs and the broader M09 contract row remain open.
