Gesher 0.1.0 runs Android apps on 64-bit Windows using AOSP ART and Android
framework services, Win32 windows, ANGLE and WebView2. It includes native x86-64
loading and arm64 translation, networking/TLS, app installation and per-user
shell integration. The installer requires Windows 10 or later; it is unsigned.
Windows may show an unsigned-app warning. Web views require Microsoft Edge
WebView2 Runtime; Setup offers its installation when absent.

This release promotes the exact installer from full main CI
[__CI_RUN__](https://github.com/gesher-runtime/gesher/actions/runs/__CI_RUN__),
commit `__SOURCE_SHA__`. Both GitHub-hosted Windows 2022/2025 suites, package
install/run/input/uninstall checks and both real-app e2e jobs must pass before
promotion. The e2e set includes native/arm64 TIC-80 and Simon Tatham's Puzzles. Publishing CI checks the
released bytes again, including installation, runtime/app smoke, the installed
oatdump inspecting the installed framework, and cleanup.

Download `gesher-setup-0.1.0.exe`. `SHA256SUMS` and
`gesher-0.1.0-manifest.json` record the installer digest, PE version, source CI
and tested artifact identity. Install per user; administrator rights are not
required. APKs open through Gesher and installed apps get Start menu shortcuts.

The supported API and hardware scope is the one documented at the source
commit, including [networking](https://github.com/gesher-runtime/gesher/blob/__SOURCE_SHA__/docs/network.md),
[WebView](https://github.com/gesher-runtime/gesher/blob/__SOURCE_SHA__/docs/webview.md)
and [native libraries](https://github.com/gesher-runtime/gesher/blob/__SOURCE_SHA__/docs/native-libs.md).
CI runners are not evidence for physical Wi-Fi/VPN/camera/sensor devices or
actual screen-reader speech. Gesher is a Windows compatibility runtime;
Android apps, especially native libraries, should be installed only from
sources you trust.
