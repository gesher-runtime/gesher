גשר — הפעלת יישומי Android ב־Windows
===================================

דרישות: Windows 10 או Windows 11 במחשב x64.
שפת הממשק של גשר נבחרת אוטומטית לפי שפות התצוגה של Windows.
עברית ואנגלית נתמכות; אם אין תרגום מתאים, מוצג הממשק באנגלית.

הפעלת יישומים
--------------
לחיצה כפולה על קובץ APK מתקינה או מעדכנת את היישום ומפעילה אותו בחלון.
אם קובצי APK משויכים לתוכנה אחרת, אפשר לבחור בגשר מתוך ״פתח באמצעות״.
אפשר להתקין גם חבילות מפוצלות מסוג XAPK או APKS.

לכל יישום מותקן שיש לו מסך פתיחה נוצר קיצור דרך בתפריט ״התחל״,
בתיקיית ״יישומי גשר״, עם שם היישום והסמל שלו.

אפשר להשתמש גם בשורת הפקודה:

    gesher-app my.apk
    gesher-app install my.apk
    gesher-app launch com.example.app
    gesher-app list
    gesher-app uninstall com.example.app

סביבת גשר
----------
ההפעלה הראשונה מפעילה את סביבת גשר ברקע. כל יישום פועל בתהליך נפרד,
והפעלות נוספות משתמשות באותה סביבה. סגירת החלון מסיימת את הפעילות.
הסביבה נעצרת אוטומטית לאחר עשר דקות ללא תהליך יישום פעיל.
אפשר לבדוק את מצבה או לעצור אותה במפורש:

    gesher-app status
    gesher-app shutdown

יישומים מותקנים והנתונים שלהם נשמרים בתיקייה:

    %LOCALAPPDATA%\Gesher\data

יומני האבחון נשמרים בתיקייה הבאה. היומנים הטכניים עשויים להיות באנגלית:

    %LOCALAPPDATA%\Gesher\logs

הרשאות, חשבונות ומצלמה
----------------------
גשר מציג בקשת אישור לפני הענקת הרשאות רגישות או גישה לאסימון חשבון.
הבקשות מוצגות בעברית כשזו שפת המערכת. ברירת המחדל היא סירוב.
כשיישום מבקש לצלם תמונה, מצלמת גשר מציגה את הכפתורים ״צילום תמונה״ ו״ביטול״.

תוכן אינטרנט ביישומים
---------------------
גשר משתמש ב־Microsoft Edge WebView2 להצגת דפי אינטרנט בתוך יישומי Android.
הרכיב כלול ב־Windows 11 ובמחשבי Windows 10 מעודכנים. אם הוא חסר,
מתקין גשר מציע להתקין אותו. נתוני האינטרנט של כל יישום נשמרים בנפרד.

הגדרות נוספות
--------------
אפשר לבחור פעילות מסוימת באמצעות ‎--activity .Other,
להפעיל ללא חלון באמצעות ‎--headless, או להגדיר שרת מתווך:

    gesher-app proxy host:port
    gesher-app proxy windows

הרחבות microG מאומתות מותקנות באמצעות gesher-app-microg.ps1.
הגדרת חשבונות, רישום המכשיר והודעות בענן נעשית בהגדרות microG עצמו.
שפתם של יישומי צד שלישי תלויה בתרגומים ובהגדרות שלהם.

דוגמת Java
-----------
להפעלת דוגמת Java המצורפת אפשר לבחור ״גשר — דוגמה״ בתפריט ״התחל״,
או להריץ:

    gesher

להפעלת תוכנית שהומרה ל־DEX:

    gesher classes.dex com.example.Main

הסרת גשר מסירה גם את סביבת גשר ואת נתוני היישומים שבתוכה.
